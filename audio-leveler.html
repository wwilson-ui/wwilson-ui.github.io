Audio Leveler

Set every clip to the same loudness before you put it in WeVideo. Your files never leave this computer.

How much leveling?

Before After Target loudness
    Using leveled files in WeVideo
    1. Level each clip here: narration, interviews, music, sound effects.
    2. Upload the new files (they end in _light, _medium or _strong) to WeVideo instead of the originals.
    3. Leave their volume at 100%. They’re already set to the same loudness, so they’ll match.
    Fixing a video that’s already finished
    1. Export your video from WeVideo and level the MP4 here. You’ll get a WAV audio file back.
    2. In WeVideo, add your exported video to a new project and turn its volume down to 0.
    3. Put the WAV on an audio track starting at exactly 0:00 so it lines up.
    4. Export again.
    What do the numbers mean?

    Loudness is the overall volume. Every leveled file is set to −16, so they all match.

    Ups and downs is how much the volume jumps around inside the file. Smaller is more even. Under about 6 usually sounds smooth for a narrated video.

    Privacy on a shared computer

    Files are processed inside this browser tab and are never uploaded. Close the tab and they’re gone from here. Delete your downloaded files from the Downloads folder when you’re done.
